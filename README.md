## 2. Summary of data collection

## 3. Information we collect

### 3.1 Information you provide directly

Depending on the feature you use, this may include:

- **Account credentials** — email address and password, if you sign in.
- **Identity and contact details** — full name, mobile phone number, email (where requested).
- **Government / identification data** — Egyptian national ID number (where required by a form).
- **Address and location details you type** — governorate, city, address, residence information (we do **not** access GPS/device location).
- **Professional / personal background** — job, education, employer, prior party membership (where requested on forms such as membership applications).
- **Request / complaint content** — text you submit in citizen requests, committee submissions, suggestions, or similar forms.
- **Files and photos** — documents or images you choose to attach (for example supporting documents or photos related to a request). Access to the photo library or camera (on supported devices) is used only when you choose to attach a file.
- **Live chat messages** — messages you send through the in-app support chat.

### 3.2 Information collected automatically

- **Technical / network data** necessary to connect to our servers (for example IP address and standard HTTP request metadata processed by the hosting infrastructure).
- **WebView / session data** when you use embedded web features (such as live chat), which may involve cookies or similar storage managed by the device’s WebView for the loaded website.

### 3.3 Information we do not intentionally collect

Based on the App’s current design and dependencies, we do **not** intentionally collect:

- Precise GPS location  
- Device contacts  
- Payment card details (the App has no in-app payments)  
- Advertising identifiers for ad targeting  
- Analytics event streams via third-party analytics SDKs
